# 用户手册

## 1. 简介

欢迎使用媒体库管理系统！本系统是一个功能强大的视频媒体库管理软件，支持本地数据库管理、NAS扫描、标签管理、NFO导入、去重复和星级评分等功能。本手册将帮助您快速上手并充分利用系统的各项功能。

## 2. 系统要求

### 2.1 硬件要求

- **CPU**: 双核2.0GHz以上
- **内存**: 4GB以上（推荐8GB）
- **硬盘**: 10GB以上可用空间
- **网络**: 稳定的互联网连接（用于获取JAVDB信息）

### 2.2 软件要求

- **操作系统**: Windows 10/11, macOS 10.14+, Linux (Ubuntu 18.04+)
- **Python**: 3.6+
- **浏览器**: Microsoft Edge（用于爬虫功能）
- **其他**: Edge WebDriver（与Edge浏览器版本匹配）

## 3. 安装与启动

### 3.1 首次安装

1. **下载系统**
   - 从项目仓库下载最新版本的系统文件
   - 解压到您选择的目录

2. **安装依赖**
   ```bash
   # 进入系统目录
   cd media
   
   # 创建虚拟环境（推荐）
   python3 -m venv media_env
   source media_env/bin/activate  # Linux/macOS
   # 或
   media_env\Scripts\activate  # Windows
   
   # 安装依赖
   pip install -r requirements.txt
   ```

3. **配置Edge WebDriver**
   - 下载与您的Edge浏览器版本匹配的Edge WebDriver
   - 将WebDriver放置在系统PATH中或指定路径

4. **启动系统**
   ```bash
   python media_library.py
   ```

### 3.2 日常启动

1. **GUI模式**
   ```bash
   python media_library.py
   ```

2. **命令行模式**
```bash
# JAVDB信息更新
python javdb_information_updater.py --code ABC-123

# 批量更新
python javdb_information_updater.py --refresh-all

# 视频标签生成
python video_tagging.py

# 按番号复制与填充（含演员复制）
python copy_javdb_info_by_code.py --folder-index 11 --dry-run --limit 5
python copy_javdb_info_by_code.py --folder-index 11 --limit 50
python copy_javdb_info_by_code.py --folder-index 11 --limit 5 --override-javdb-info
```

## 6. 高级功能

### 6.1 JAVDB信息获取

#### 6.1.1 单个视频信息获取

1. 在视频列表中选中视频
2. 在详情面板中点击"获取JAVDB信息"按钮
3. 系统将自动从JAVDB获取视频信息
4. 获取完成后，信息将显示在详情面板中

#### 6.1.2 批量信息获取

1. 选择菜单栏的"工具" > "JAVDB信息更新器"
2. 选择更新模式：
   - 按番号刷新：输入特定番号进行更新
   - 刷新所有视频：更新所有视频的JAVDB信息
3. 系统将自动批量获取信息

#### 6.1.3 按番号复制与填充（含演员复制）

该工具用于按番号在本地数据库内进行“信息复制与填充”，无需联网抓取。当目标视频缺少`javdb_info`字段或标签时，可从同番号的来源视频复制过来；当目标视频当前无任何演员关联时，会自动复制来源视频的演员关联。

适用场景：
- 同番号多版本（不同文件夹/分辨率）需要信息对齐
- 需要补齐缺失的`javdb_info`字段或标签
- 目标视频没有演员关联，需要从已有来源继承演员

使用示例：
```bash
# 干跑预览（不写入），查看复制与变更统计
python copy_javdb_info_by_code.py --folder-index 11 --dry-run --limit 5

# 小批量正式入库（写入数据库）
python copy_javdb_info_by_code.py --folder-index 11 --limit 50

# 覆盖已有javdb_info字段（不建议，仅在需要统一覆盖时使用）
python copy_javdb_info_by_code.py --folder-index 11 --limit 5 --override-javdb-info
```

行为说明：
- 来源选择：按“完整度优先、更新时间次之”排序选择来源视频
- 字段填充：默认仅填充目标为空的`javdb_info`字段；使用`--override-javdb-info`可覆盖已有值（谨慎使用）
- 标签复制：复制来源的标签到目标，补齐缺失标签
- 演员复制：仅当目标视频当前无任何演员关联时复制来源的演员关联，不覆盖已有演员
- 安全性：默认支持干跑，日志中会标出“关联演员”和“复制演员 X 条”等提示

日志示例（节选）：
```text
候选来源：IPTD-981（完整度 18/22，更新 2024-07-01）
填充字段：title, release_date, score ...
复制标签：3 条（中文字幕, 教师, 单体）
关联演员：复制演员 3 条（Rio, 柚木ティナ, 提娜）
```

## 12. 常见问题

### 12.1 安装问题

**Q: 安装时提示缺少依赖怎么办？**
A: 确保已正确安装所有依赖：
```bash
pip install -r requirements.txt
```

**Q: Edge WebDriver如何配置？**
A: 
1. 下载与您的Edge浏览器版本匹配的Edge WebDriver
2. 将WebDriver添加到系统PATH中
3. 或在配置文件中指定WebDriver路径

### 12.2 功能问题

**Q: 无法获取JAVDB信息怎么办？**
A:
1. 检查网络连接
2. 确认代理设置正确
3. 尝试手动登录JAVDB网站
4. 更新Edge WebDriver到最新版本

**Q: 视频封面无法生成怎么办？**
A:
1. 确认视频文件格式受支持
2. 检查是否安装了OpenCV
3. 尝试使用其他视频文件测试

**Q: 批量操作速度很慢怎么办？**
A:
1. 减少同时处理的文件数量
2. 增加系统内存
3. 关闭不必要的后台程序

### 12.3 性能问题

**Q: 程序运行缓慢怎么办？**
A:
1. 重启程序
2. 清理数据库（工具 > 数据库维护）
3. 增加系统内存
4. 关闭不必要的功能

**Q: 数据库文件很大怎么办？**
A:
1. 执行数据库优化（工具 > 数据库维护 > 优化数据库）
2. 清理不需要的数据
3. 考虑归档旧数据

### 12.4 数据问题

**Q: 数据库损坏怎么办？**
A:
1. 从备份恢复数据库
2. 如果没有备份，尝试修复数据库
3. 联系技术支持

**Q: 视频信息不正确怎么办？**
A:
1. 手动编辑视频信息
2. 重新获取JAVDB信息
3. 检查数据源是否正确
