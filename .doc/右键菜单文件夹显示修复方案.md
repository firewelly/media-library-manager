# 右键菜单文件夹显示修复方案

## 问题描述
当前右键菜单中的文件夹显示存在两个问题：
1. 只显示文件夹的基本名称（basename），没有显示完整路径
2. 没有检查文件夹的在线状态，导致显示"离线"文件夹

## 问题代码位置
在 `media_library.py` 的第6000-6060行左右，右键菜单创建代码：

```python
# 获取所有在线文件夹
self.cursor.execute("SELECT folder_path FROM folders WHERE is_active = 1")
online_folders = self.cursor.fetchall()

for folder in online_folders:
    folder_path = folder[0]
    folder_name = os.path.basename(folder_path)  # 只显示基本名称
    move_menu.add_command(label=folder_name, 
                        command=lambda fp=folder_path: self.move_file_to_folder(video_info['id'], video_info['path'], fp))
```

## 修复方案

### 1. 添加在线文件夹检查方法
在 `media_library.py` 中添加一个辅助方法来获取在线文件夹：

```python
def get_online_folders(self):
    """获取所有在线的活跃文件夹"""
    try:
        self.cursor.execute("SELECT folder_path FROM folders WHERE is_active = 1")
        all_folders = [row[0] for row in self.cursor.fetchall()]
        
        # 只返回在线（可访问）的文件夹
        online_folders = []
        for folder_path in all_folders:
            if os.path.exists(folder_path) and os.path.isdir(folder_path):
                online_folders.append(folder_path)
        
        return online_folders
    except Exception as e:
        print(f"获取在线文件夹失败: {e}")
        return []

def format_folder_display_name(self, folder_path):
    """格式化文件夹显示名称"""
    # 获取文件夹的基本名称
    base_name = os.path.basename(folder_path)
    
    # 如果基本名称太短或太通用，显示更多路径信息
    if len(base_name) <= 3 or base_name.lower() in ['movies', 'videos', 'films']:
        # 显示父目录和当前目录
        parent_dir = os.path.basename(os.path.dirname(folder_path))
        if parent_dir:
            return f"{parent_dir}/{base_name}"
        else:
            return base_name
    
    return base_name
```

### 2. 修改右键菜单创建代码
替换原有的右键菜单创建逻辑：

```python
# 获取所有在线文件夹（修复后的版本）
online_folders = self.get_online_folders()

for folder_path in online_folders:
    # 使用格式化后的显示名称
    display_name = self.format_folder_display_name(folder_path)
    move_menu.add_command(label=display_name, 
                        command=lambda fp=folder_path: self.move_file_to_folder(video_info['id'], video_info['path'], fp))
```

### 3. 批量操作菜单的修复
同样的修复需要应用到批量操作的菜单中：

```python
# 批量迁移JavSP到
migrate_menu = tk.Menu(context_menu, tearoff=0)
context_menu.add_cascade(label=f"批量迁移JavSP到 ({len(selected_videos)}个文件)", menu=migrate_menu)

# 获取在线文件夹
online_folders = self.get_online_folders()
for folder_path in online_folders:
    display_name = self.format_folder_display_name(folder_path)
    migrate_menu.add_command(label=display_name,
                           command=lambda fp=folder_path: self.batch_migrate_javsp_files_to_library(fp))

# 批量复制JavSP到
copy_menu = tk.Menu(context_menu, tearoff=0)
context_menu.add_cascade(label=f"批量复制JAVSP到 ({len(selected_videos)}个文件)", menu=copy_menu)

for folder_path in online_folders:
    display_name = self.format_folder_display_name(folder_path)
    copy_menu.add_command(label=display_name,
                         command=lambda fp=folder_path: self.batch_copy_javsp_files_to_library(fp))
```

## 显示效果
修复后的显示效果：
- 对于通用名称如 "movies"，显示为 "parent/movies"
- 对于特定名称如 "JAV-2024"，显示为 "JAV-2024"
- 只显示实际可访问的在线文件夹
- 离线文件夹不会出现在菜单中
