# 复制JavSP到功能文档

## 功能概述

"复制JavSP到"功能是在现有的"迁移JavSP到"功能基础上新增的复制功能。与迁移功能不同，复制功能会保留源文件，仅将文件及其相关附属文件复制到目标媒体库中。

## 功能特点

- **保留源文件**：复制操作不会删除原始文件，确保数据安全
- **完整的文件处理**：支持主视频文件、字幕文件、封面图片、元数据文件等附属文件的复制
- **层级结构保持**：保持原有的目录结构，确保文件组织的一致性
- **冲突处理**：当目标位置已存在同名文件时，提供智能冲突解决机制
- **进度显示**：批量复制时提供详细的进度显示和结果统计

## 技术实现

### 核心模块

复制功能的核心实现位于 `utils/javsp_copy.py` 文件中，主要包含以下函数：

- `copy_single()`: 单个文件的复制操作
- `find_source_root_for_path()`: 查找源文件根目录
- `compute_javsp_relative_subdir()`: 计算相对子目录路径
- `collect_javsp_sidecar_files()`: 收集附属文件
- `resolve_copy_conflict()`: 解决文件冲突

### 用户界面

在 `media_library.py` 中添加了以下功能：

- `copy_javsp_file_to_library()`: 单个文件复制功能
- `batch_copy_javsp_files_to_library()`: 批量文件复制功能

### 菜单集成

在右键上下文菜单中添加了：
- 单文件："复制JavSP到"子菜单
- 多文件："批量复制JavSP到"子菜单

## 使用说明

### 单个文件复制

1. 在视频列表中右键点击要复制的文件
2. 选择"复制JavSP到"菜单
3. 从子菜单中选择目标媒体库
4. 等待复制完成

### 批量文件复制

1. 选择多个要复制的视频文件（按住Ctrl或Shift键）
2. 右键点击选中的文件
3. 选择"批量复制JavSP到"菜单
4. 从子菜单中选择目标媒体库
5. 等待批量复制完成，可以查看进度和结果

## 与迁移功能的区别

| 功能 | 迁移JavSP到 | 复制JavSP到 |
|------|-------------|-------------|
| 源文件 | 删除 | 保留 |
| 操作类型 | 移动 | 复制 |
| 风险 | 较高（文件丢失风险） | 较低（源文件保留） |
| 磁盘空间 | 不变 | 增加 |
| 使用场景 | 整理文件 | 备份文件 |

## 错误处理

复制功能包含完善的错误处理机制：

- **文件访问错误**：当源文件无法访问时，显示具体的错误信息
- **磁盘空间不足**：检测目标磁盘空间，空间不足时给出提示
- **权限错误**：处理文件权限问题，提供相应的错误信息
- **冲突解决**：当目标文件已存在时，提供重命名、跳过或覆盖选项

## 性能优化

- **批量处理**：支持批量复制，提高效率
- **进度显示**：实时显示复制进度和状态
- **内存优化**：大文件复制时采用流式处理，避免内存溢出
- **取消支持**：批量复制过程中可以随时取消操作

## 数据库更新

复制完成后，系统会自动：

1. 更新数据库中的文件路径信息
2. 保持元数据的一致性
3. 更新媒体库索引
4. 刷新界面显示

## 安全考虑

- **文件完整性**：复制完成后验证文件完整性
- **元数据保持**：确保文件的创建时间、修改时间等元数据得到保持
- **事务处理**：数据库操作采用事务处理，确保数据一致性
- **备份机制**：在关键操作前创建数据库备份点
