# 视频标签系统设计文档
 - 版本: 开发版
 - 最后更新: 2025-11-29
 - 适用系统: Windows/macOS/Linux

## 1. 系统概述

视频标签系统是一个基于词汇表的轻量级自动标签生成工具，专为媒体库中的视频内容提供智能分类和标签生成功能。该系统能够从视频文件名和标题中提取特征词汇，并基于预定义的词汇表和规则生成相关标签，帮助用户更有效地组织和搜索媒体库中的内容。

## 2. 核心功能

### 2.1 特征提取
- 从视频文件名中提取特征词汇
- 支持基于番号前缀的特征映射
- 从视频标题中提取关键词

### 2.2 标签生成
- 基于特征词汇和预定义规则生成标签
- 支持标签分类（人物特征、身材特征、服装道具等）
- 实现标签权重计算和阈值过滤

### 2.3 数据库交互
- 从SQLite数据库读取视频信息
- 更新视频标签到数据库
- 支持批量处理模式

### 2.4 测试与报告
- 提供单视频和批量测试功能
- 生成详细的测试报告
- 支持交互式标签更新确认

## 3. 系统架构

![系统架构图](系统架构图.png)

系统主要由以下组件构成：

1. **词汇表管理器**：加载和管理词汇表，为每个词汇分配权重
2. **特征提取器**：从文件名和标题中提取特征词汇
3. **标签生成器**：基于特征和规则生成标签
4. **标签合并器**：合并现有标签和新生成标签
5. **数据库接口**：与SQLite数据库交互
6. **测试与报告模块**：提供测试功能和生成报告

## 5. 数据模型

### 5.1 词汇表结构
词汇表存储在文本文件中，每行一个词汇，按重要性排序。系统为每个词汇分配以下属性：
- `freq`：基于位置的频次权重
- `tfidf`：基于位置的TF-IDF权重
- `type`：词汇类型

### 5.2 标签规则
系统使用预定义规则进行标签分类，每个规则包含：
- 关键词列表
- 权重阈值
- 频次阈值

### 5.3 数据库表结构
系统主要与`videos`表交互，关键字段包括：
- `id`：视频ID
- `file_name`：文件名
- `file_path`：文件路径
- `file_size`：文件大小
- `title`：标题
- `tags`：标签字符串（逗号分隔）
- `updated_at`：更新时间

## 6. 技术实现细节

### 6.1 特征提取算法
- 支持多种番号格式识别（如ABC-123、FC2-xxxxxx等）
- 利用正则表达式匹配番号前缀
- 使用结巴分词库进行中文分词

### 6.2 标签生成算法
- 基于特征频率和权重的综合评估
- 实现标签分类系统，包括人物特征、身材特征等7大类
- 支持标签数量限制和优先级排序

### 6.3 性能优化
- 批量处理机制减少数据库交互
- 词汇表缓存减少文件I/O
- 基于阈值过滤减少无效标签生成

## 7. 配置与依赖

### 7.1 配置文件
- `vocabulary_tags.txt`：词汇表文件
- 可通过修改该文件自定义标签词汇

### 7.2 依赖项
- `sqlite3`：数据库操作
- `jieba`：中文分词
- `re`：正则表达式处理
- `os`、`json`、`datetime`等标准库

## 8. 使用指南

### 8.1 测试模式
```bash
python video_tagging.py
# 选择 1 进入测试模式，系统将处理3个大视频文件
```

### 8.2 批量处理模式
```bash
python video_tagging.py
# 选择 2 进入批量模式，系统将处理数据库中所有视频
```

### 8.3 自定义词汇表
编辑`vocabulary_tags.txt`文件，按重要性顺序添加或修改词汇。词汇越靠前，权重越高。

## 9. 测试报告示例

系统会生成详细的测试报告，包含以下信息：
- 测试时间和视频数量
- 每个视频的原始标签和新生成标签
- 提取的特征词汇
- 特征频率统计
- 平均提取特征数等统计信息

报告文件命名格式：`tagging_test_report_YYYYMMDD_HHMMSS.txt`

## 10. 限制与注意事项

1. 系统依赖于词汇表的完整性和质量
2. 目前仅支持从文件名和标题中提取特征
3. 标签生成基于规则，可能需要人工审核和调整
4. 批量处理大型数据库时可能需要较长时间
5. 显存使用优化至8G以下，适合一般配置的计算机

- `MDYD` -> ['人妻', '熟女', '少妇']
- `EBOD` -> ['巨乳', '大奶']
