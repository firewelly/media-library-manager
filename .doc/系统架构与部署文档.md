# 系统架构与部署文档
 - 版本: 开发版
 - 最后更新: 2025-11-29
 - 适用系统: Windows/macOS/Linux

## 1. 系统概述

本媒体库管理系统是一个基于Python开发的跨平台视频媒体库管理软件，主要功能包括本地数据库管理、NAS扫描、标签管理、NFO导入、去重复和星级评分等。系统采用模块化设计，具有良好的可扩展性和可维护性。

## 2. 系统架构

### 2.1 整体架构

系统采用分层架构设计，主要分为以下几个层次：

1. **表示层（Presentation Layer）**
   - 基于Tkinter的GUI界面
   - 提供用户交互和操作界面
   - 支持多平台（Windows、macOS、Linux）

2. **业务逻辑层（Business Logic Layer）**
   - 核心功能模块
   - 数据处理和业务规则
   - 外部服务集成

3. **数据访问层（Data Access Layer）**
   - SQLite数据库操作
   - 文件系统访问
   - 外部API调用

4. **基础设施层（Infrastructure Layer）**
   - 系统配置管理
   - 日志记录
   - 网络代理支持

### 2.2 模块划分

系统主要由以下模块组成：

1. **主应用模块（media_library.py）**
   - GUI界面实现
   - 核心业务逻辑
   - 用户交互处理

2. **JAVDB爬虫模块（javdb_crawler.py）**
   - JAVDB网站数据爬取
   - 演员信息获取
   - 番号信息更新

3. **JAVDB登录助手模块（javdb_login_helper.py）**
   - 登录状态管理
   - 会话保持
   - 验证码处理

4. **JAVDB信息更新器模块（javdb_information_updater.py）**
   - 批量信息更新
   - 番号刷新
   - 数据同步

5. **视频标签模块（video_tagging.py）**
   - 自动标签生成
   - 特征提取
   - 标签管理

6. **演员信息管理模块（javdb_actor_crawler.py）**
   - 演员信息爬取
   - 头像下载
   - 数据更新

7. **视频分析模块（video_analysis.py）**
   - 视频元数据提取
   - 封面生成
   - 视频处理

## 5. 系统配置

### 5.1 配置文件

1. **主配置文件（config.json）**
   ```json
   {
       "proxy": {
           "enabled": true,
           "host": "127.0.0.1",
           "port": 1080
       },
       "crawler": {
           "delay_between_requests": 2.0,
           "headless": true
       }
   }
   ```

2. **GUI配置文件（gui_config.json）**
   ```json
   {
     "columns": {
       "title": {
         "width": 400,
         "position": 0,
         "text": "标题"
       },
       "actors": {
         "width": 150,
         "position": 1,
         "text": "演员"
       }
       // ... 其他列配置
     }
   }
   ```

3. **JAVSP配置文件（javsp_config.yaml）**
   ```yaml
   # JAVSP相关配置
   database:
     path: media_library.db
   crawler:
     user_agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
   ```

### 5.2 环境变量

系统支持以下环境变量：

1. **代理设置**
   - `HTTP_PROXY`: HTTP代理地址
   - `HTTPS_PROXY`: HTTPS代理地址

2. **数据库设置**
   - `DB_PATH`: 数据库文件路径

3. **日志设置**
   - `LOG_LEVEL`: 日志级别（DEBUG/INFO/WARNING/ERROR/CRITICAL）

## 6. 部署方案

### 6.1 系统要求

1. **操作系统**
   - Windows 10/11
   - macOS 10.14+
   - Linux (Ubuntu 18.04+)

2. **硬件要求**
   - CPU: 双核2.0GHz以上
   - 内存: 4GB以上（推荐8GB）
   - 硬盘: 10GB以上可用空间
   - 网络: 稳定的互联网连接

3. **软件要求**
   - Python 3.6+
   - Edge浏览器（用于爬虫）
   - Edge WebDriver

### 6.2 安装步骤

1. **环境准备**
   ```bash
   # 安装Python 3.6+
   # macOS使用Homebrew
   /opt/homebrew/bin/brew install python3
   
   # 创建虚拟环境
   python3 -m venv media_env
   source media_env/bin/activate  # Linux/macOS
   # 或
   media_env\Scripts\activate  # Windows
   ```

2. **依赖安装**
   ```bash
   # 安装基础依赖
   pip install -r requirements.txt
   
   # 安装Edge WebDriver
   # 下载对应版本的Edge WebDriver并配置到PATH
   ```

3. **数据库初始化**
   ```bash
   # 运行主程序，数据库会自动创建
   python media_library.py
   ```

### 6.4 代理与镜像源

- 代理：GitHub/HuggingFace 使用 socks5（macOS/Linux `127.0.0.1:1080`，Windows `127.0.0.1:8800`）
- 镜像源：pip/conda/Homebrew 优先使用清华镜像；Homebrew 路径为 `/opt/homebrew/bin/brew`
- 部署于 Linux 服务器时，统一走 socks5 代理并验证出口连通性

### 6.5 Edge WebDriver 路径与权限

- Windows: `C:\bin\edgedriver_win64\msedgedriver.exe`
- macOS Intel: `/usr/local/bin/edgedriver_mac64/msedgedriver`
- macOS Apple Silicon: `/usr/local/bin/edgedriver_mac64_m1/msedgedriver`
- Linux: `/usr/local/bin/edgedriver_linux64/msedgedriver`
- 默认备用：`/usr/local/bin/edgedriver_mac64/msedgedriver`
- 提示：确保驱动可执行权限；建议使用驱动管理工具自动下载与配置，或将路径加入 `PATH`

