# 媒体库管理系统项目概述
 - 版本: 开发版
 - 最后更新: 2025-11-29
 - 适用系统: Windows/macOS/Linux

## 1. 项目简介

媒体库管理系统是一个功能完备的视频内容管理平台，专注于视频文件的组织、分析、去重和元数据管理。该系统结合了网络爬虫、视频内容分析、数据库管理和用户界面等多个组件，提供了从视频元数据获取、内容特征分析到重复文件检测与清理的全流程解决方案。

## 2. 系统架构

系统采用模块化设计，主要包含以下核心组件：

1. **数据爬取模块**：通过网络爬虫从JAVDB等网站获取视频元数据，包括标题、演员、标签、发行日期等信息。

2. **视频分析模块**：提供多模态视频内容分析功能，能够提取视频帧并使用AI模型进行内容理解和标签匹配。

3. **数据库管理模块**：基于SQLite构建的数据库系统，存储视频元数据、演员信息、标签和文件关联等数据。

4. **文件管理模块**：负责视频文件的导入、路径管理、MD5计算和完整性检查。

5. **去重与清理模块**：检测并清理重复视频记录，支持多种去重策略。

6. **批量处理模块**：提供批量视频分析、元数据更新等功能，支持并行处理以提高效率。

## 3. 核心功能

### 3.1 视频元数据获取
- 支持通过番号搜索特定视频信息
- 自动获取视频封面、演员信息、标签等元数据
- 支持批量爬取和单视频爬取两种模式
- 实现了代理支持和反爬虫策略
- 视频信息更新工具：支持番号提取与格式化、数据库操作、视频信息更新、JAVDB信息爬取等功能
- 演员档案修复工具：支持演员头像URL提取、头像下载、重复演员合并、从视频封面提取人脸作为头像等功能

### 3.2 视频内容分析
- 基于多模态AI模型的视频内容理解
- 自动抽取视频帧并进行图像分析
- 支持自定义标签词汇库匹配
- 生成详细的分析报告和标签频率统计

### 3.3 数据库管理
- 完整的数据库表结构设计（8个主要表）
- 支持SQLite数据库操作
- 提供数据库备份和恢复功能
- 实现了数据完整性约束和索引优化

### 3.4 重复视频检测与清理
- 支持基于文件路径、文件名和MD5值的重复检测
- 提供交互式清理界面，允许用户选择删除重复记录
- 自动处理关联数据的级联删除
- 提供详细的重复检测报告

### 3.5 批量处理功能
- 支持批量导入和更新视频元数据
- 实现并行视频分析以提高效率
- 支持SMB网络路径访问
- 提供断点续传和错误恢复机制

## 4. 技术栈

- **编程语言**：Python 3.x
- **数据库**：SQLite
- **网络爬虫**：Requests, Selenium
- **视频处理**：OpenCV (cv2), PIL
- **AI模型集成**：LM Studio API (qwen2.5-vl-7b)
- **数据处理**：Pandas, NumPy, JSON, CSV
- **Web技术**：HTML, JavaScript (用于GUI)
- **操作系统支持**：跨平台 (Windows, macOS, Linux)

## 5. 项目结构

项目采用模块化的文件组织结构，将不同功能的脚本分离到独立文件中，便于维护和扩展。主要目录和文件说明：

- **核心脚本文件**：包含各种功能实现的Python脚本
- **数据库相关**：数据库模式文档、ER图和初始化脚本
- **配置文件**：系统配置、GUI配置等
- **文档目录**：包含各类技术文档和使用指南
- **测试目录**：测试脚本和示例
- **媒体资源**：封面图片存储目录
- **报告目录**：生成的分析报告和检查报告

## 7. 系统要求

- Python 3.7或更高版本
- 足够的磁盘空间存储视频和元数据
- 支持OpenCV的图形处理环境
- （可选）用于AI分析的LM Studio服务器
- （可选）用于爬虫的Edge浏览器和驱动

## 8. 使用流程

1. **初始化**：运行初始化脚本创建数据库
2. **配置**：设置config.json和config.py中的参数
3. **导入**：使用导入脚本添加视频文件
4. **爬取元数据**：运行爬虫脚本获取视频元数据
5. **内容分析**：使用视频分析工具分析视频内容
6. **去重清理**：检测并清理重复视频记录
7. **维护更新**：定期运行更新脚本保持数据最新

## 9. 开发与扩展

项目设计考虑了可扩展性，支持以下扩展方式：
- 添加新的爬虫来源
- 集成不同的AI分析模型
- 扩展数据库结构
- 开发新的批量处理功能
- 增强用户界面

## 10. 总结

媒体库管理系统是一个功能全面、架构清晰的视频内容管理平台，通过整合爬虫技术、AI分析和数据库管理，为用户提供了高效的视频组织和管理解决方案。系统支持多种使用场景，从个人媒体库管理到小型媒体服务器应用，都能满足需求。
