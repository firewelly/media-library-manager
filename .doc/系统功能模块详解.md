# 媒体库管理系统功能模块详解

## 1. 数据爬取模块

### 1.1 JAVDB爬虫系统 (javdb_crawler.py)

**功能概述**：该模块负责从JAVDB网站爬取视频元数据，是整个系统的元数据获取核心。

**核心功能点**：
- 基于番号的视频搜索
- 视频详情页解析（标题、番号、发行日期、时长、评分等）
- 演员信息提取和性别判断
- 标签提取和分类
- 封面图片下载
- 磁力链接提取
- 登录认证支持
- 代理设置和随机延迟

**关键实现**：
```python
# 主要类和方法
- search_video_by_code(code): 按番号搜索视频
- get_video_detail_links(url, max_pages): 获取视频详情链接
- parse_detail(url): 解析视频详情页
- handle_login(): 处理登录认证
- crawl_by_video_codes(codes): 批量爬取视频信息
- crawl_homepage_videos(max_pages): 从首页爬取视频
```

**配置参数**：
- SOCKS5代理设置
- 请求延迟配置
- 无头模式设置

### 1.2 演员爬虫模块

**功能概述**：专门用于爬取演员信息的模块，支持批量获取和详情页爬取。

**相关文件**：
- `actor_crawler_with_db.py`: 带数据库支持的演员爬虫
- `actor_crawler_headless_db.py`: 无头模式的演员爬虫
- `actor_detail_crawler.py`: 演员详情页爬虫
- `javdb_actor_all.py`: 全量演员爬取
- `javdb_actor_stream.py`: 流式演员爬取

**核心功能**：
- 演员列表爬取
- 演员详细信息提取（生日、身高、三围等）
- 演员头像下载
- 演员作品关联

## 2. 视频分析模块

### 2.1 视频多模态分析器 (video_multimodal_analyzer.py)

**功能概述**：基于AI模型的视频内容分析工具，能够提取视频帧并进行内容理解。

**核心功能点**：
- 视频帧提取（均匀分布采样）
- 帧图像转换为base64编码
- 调用LM Studio的多模态模型进行图像分析
- 词汇标签匹配
- 分析结果JSON保存
- 详细报告生成

**关键实现**：
```python
class VideoMultimodalAnalyzer:
    def extract_frames(video_path, num_frames=10):  # 抽取视频帧
    def analyze_frame_with_llm(frame_base64, frame_index):  # 使用LLM分析帧
    def match_vocabulary_tags(analysis_text):  # 匹配词汇标签
    def analyze_video(video_path, output_dir, num_frames=10):  # 分析整个视频
```

**技术细节**：
- 使用OpenCV (cv2)进行视频处理
- 集成LM Studio的qwen2.5-vl-7b模型
- 支持多服务器地址自动检测

## 3. 数据库管理模块

### 3.1 数据库模式与结构 (database_schema_documentation.md)

**功能概述**：定义了系统的数据库表结构和关系，是整个系统数据存储的基础。

**主要表结构**：
- **videos**: 存储视频文件信息
- **actors**: 存储演员信息
- **video_actors**: 视频和演员的多对多关联表
- **javdb_info**: 存储从JAVDB获取的视频元数据
- **tags**: 存储标签信息
- **javdb_tags**: 存储从JAVDB获取的标签
- **javdb_info_tags**: javdb_info和javdb_tags的多对多关联表
- **folders**: 存储文件夹信息

**表关系**：
- videos与actors：多对多关系，通过video_actors表关联
- videos与javdb_info：一对一关系
- javdb_info与javdb_tags：多对多关系，通过javdb_info_tags表关联
- videos与folders：多对一关系

### 3.2 数据库操作工具

**功能概述**：提供数据库初始化、备份、查询等操作的工具脚本。

**相关文件**：
- `init_database.py`: 数据库初始化
- `database_extension.py`: 数据库结构扩展
- `local_db_write_smoke_test.py`: 数据库写入测试
- `test_sql_direct.py`: SQL直接操作测试
- `test_sql_query.py`: SQL查询测试

**核心功能**：
- 创建数据库表结构
- 初始化默认数据
- 数据库备份和恢复
- 数据导入和导出

## 8. 总结

媒体库管理系统的各个功能模块相互协作，形成了一个完整的视频内容管理生态系统。从数据获取、内容分析到存储管理和去重清理，每个模块都有其特定的职责和实现方式。系统设计注重模块化和可扩展性，便于后续功能增强和维护。通过合理使用这些功能模块，用户可以高效地管理和分析大量视频文件，提高媒体库的组织性和可访问性。
