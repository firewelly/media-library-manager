## 概述

媒体库管理系统使用SQLite数据库存储视频文件信息、演员信息、标签信息等。本文档详细说明数据库结构、表关系以及关键概念。

## 什么是"在线的文件"

在媒体库管理系统中，"在线的文件"是指当前存储在可访问位置的文件。系统通过检查文件路径是否实际存在来确定文件是否在线。

- **在线文件** (`is_online = 1`)：文件路径存在，可以正常访问
- **离线文件** (`is_online = 0`)：文件路径不存在，可能已被移动、删除或存储在未连接的设备上

系统会定期检查文件状态，更新`is_online`字段。当文件被移动或删除后，系统会将其标记为离线，但保留其元数据信息，方便用户管理和找回。

## 相关SQL语句

### 查询所有在线文件

```sql
SELECT * FROM videos WHERE is_online = 1;
```

### 查询所有离线文件

```sql
SELECT * FROM videos WHERE is_online = 0;
```

### 更新文件在线状态

```sql
UPDATE videos SET is_online = 1 WHERE path = '文件路径';
```

### 查询特定视频的所有标签

```sql
SELECT t.* FROM tags t
JOIN video_tags vt ON t.id = vt.tag_id
WHERE vt.video_id = 视频ID;
```

### 查询特定标签的所有视频

```sql
SELECT v.* FROM videos v
JOIN video_tags vt ON v.id = vt.video_id
JOIN tags t ON vt.tag_id = t.id
WHERE t.name = '标签名称';
```

### 查询特定演员的所有视频

```sql
SELECT v.* FROM videos v
JOIN video_actors va ON v.id = va.video_id
JOIN actors a ON va.actor_id = a.id
WHERE a.name = '演员姓名';
```

### 查询特定视频的JAVDB信息

```sql
SELECT ji.*, GROUP_CONCAT(jt.name) AS tags
FROM javdb_info ji
LEFT JOIN javdb_info_tags jit ON ji.id = jit.javdb_info_id
LEFT JOIN javdb_tags jt ON jit.tag_id = jt.id
WHERE ji.video_id = 视频ID
GROUP BY ji.id;
```

### 添加新视频记录

```sql
INSERT INTO videos (title, code, path, file_size, duration, is_online, created_at, updated_at)
VALUES ('标题', '番号', '文件路径', 文件大小, 时长, 1, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP);
```

### 添加新标签

```sql
INSERT INTO tags (name, category, color, created_at, updated_at)
VALUES ('标签名称', '类别', '#FF0000', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP);
```

### 为视频添加标签关联

```sql
INSERT INTO video_tags (video_id, tag_id)
VALUES (视频ID, 标签ID);
```

### 统计在线和离线文件数量

```sql
SELECT 
    is_online,
    COUNT(*) as count,
    SUM(file_size) as total_size
FROM videos
GROUP BY is_online;
```

### 查询最受欢迎的标签（使用次数最多）

```sql
SELECT t.name, COUNT(vt.video_id) as usage_count
FROM tags t
JOIN video_tags vt ON t.id = vt.tag_id
GROUP BY t.id
ORDER BY usage_count DESC
LIMIT 10;
```

## 标签系统说明

标签系统采用多对多关系设计，允许一个视频拥有多个标签，一个标签也可以关联多个视频。

### 标签类别

系统中的标签可以按类别分组，常见的类别包括：
- 内容类型（如：剧情、动作、科幻）
- 风格特征（如：复古、现代、艺术）
- 技术特点（如：4K、HDR、杜比音效）
- 评级（如：成人、青少年、全年龄）
- 自定义类别

### 标签颜色

标签可以使用颜色进行视觉区分，帮助用户快速识别不同类型的标签。

### JAVDB标签

从JAVDB网站获取的标签存储在单独的`javdb_tags`表中，通过`javdb_info_tags`表与JAVDB信息关联。这种设计允许系统区分本地标签和从JAVDB获取的标签，并为未来的扩展提供灵活性。

## 数据库维护

### 定期检查文件状态

建议定期运行文件状态检查，更新`is_online`字段：

```python
import os
import sqlite3

def update_file_status(db_path):
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    
    # 获取所有视频记录
    cursor.execute("SELECT id, path FROM videos")
    videos = cursor.fetchall()
    
    for video_id, path in videos:
        is_online = 1 if os.path.exists(path) else 0
        cursor.execute("UPDATE videos SET is_online = ? WHERE id = ?", (is_online, video_id))
    
    conn.commit()
    conn.close()
```

### 清理孤立记录

定期清理没有关联的记录，保持数据库整洁：

```sql
-- 删除没有关联视频的video_actors记录
DELETE FROM video_actors 
WHERE video_id NOT IN (SELECT id FROM videos) 
   OR actor_id NOT IN (SELECT id FROM actors);

-- 删除没有关联视频的video_tags记录
DELETE FROM video_tags 
WHERE video_id NOT IN (SELECT id FROM videos) 
   OR tag_id NOT IN (SELECT id FROM tags);
```

## 总结

媒体库管理系统的数据库设计采用关系型模型，通过多对多关系表实现灵活的关联。系统特别关注文件状态管理，区分在线和离线文件，确保用户能够有效管理媒体资源。标签系统提供了强大的分类和检索功能，支持多维度内容组织。
