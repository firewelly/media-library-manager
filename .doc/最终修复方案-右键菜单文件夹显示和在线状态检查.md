# 最终修复方案：右键菜单文件夹显示和在线状态检查

## 问题总结
通过代码分析，确认了右键菜单中文件夹显示的两个主要问题：

1. **显示不完整**：只显示文件夹的基本名称（`os.path.basename`），没有显示完整路径信息
2. **包含离线文件夹**：只检查数据库中的`is_active=1`，没有验证文件夹的实际可访问性

## 参考实现
`resumable_smart_importer.py`中的`get_active_folders`方法提供了完美的参考实现：

```python
def get_active_folders(self) -> List[str]:
    """获取所有活跃且在线的文件夹路径"""
    try:
        self.cursor.execute("SELECT folder_path FROM folders WHERE is_active = 1")
        all_folders = [row[0] for row in self.cursor.fetchall()]
        
        # 只返回在线（可访问）的文件夹
        online_folders = []
        for folder in all_folders:
            if os.path.exists(folder) and os.path.isdir(folder):
                online_folders.append(folder)
                print(f"✓ 在线文件夹: {folder}")
            else:
                print(f"✗ 离线文件夹: {folder}")
        
        return online_folders
    except Exception as e:
        print(f"获取活跃文件夹失败: {e}")
        return []
```

```python
def get_online_folders(self):
    """获取所有在线的活跃文件夹"""
    try:
        self.cursor.execute("SELECT DISTINCT folder_path FROM folders WHERE is_active = 1 ORDER BY folder_path")
        all_folders = [row[0] for row in self.cursor.fetchall()]
        
        # 只返回在线（可访问）的文件夹
        online_folders = []
        for folder_path in all_folders:
            if os.path.exists(folder_path) and os.path.isdir(folder_path):
                online_folders.append(folder_path)
                print(f"✓ 在线文件夹: {folder_path}")
            else:
                print(f"✗ 离线文件夹: {folder_path}")
        
        return online_folders
    except Exception as e:
        print(f"获取在线文件夹失败: {e}")
        return []

def format_folder_display_name(self, folder_path):
    """格式化文件夹显示名称，解决基本名称过于通用的问题"""
    # 获取文件夹的基本名称
    base_name = os.path.basename(folder_path)
    
    # 如果基本名称太短或太通用，显示更多路径信息
    generic_names = ['movies', 'videos', 'films', 'video', 'movie', 'film', 
                    'mv', 'vd', 'fm', '媒体', '视频', '电影']
    
    if len(base_name) <= 3 or base_name.lower() in generic_names:
        # 显示父目录和当前目录
        parent_dir = os.path.basename(os.path.dirname(folder_path))
        if parent_dir:
            return f"{parent_dir}/{base_name}"
        else:
            return base_name
    
    return base_name
```

## 性能考虑

1. **文件夹检查**：`get_online_folders`方法会对每个文件夹进行存在性检查，对于大量文件夹（>100个）可能会有轻微的性能影响
2. **缓存机制**：考虑在后续版本中添加缓存机制，避免每次都进行文件系统检查
3. **异步处理**：对于极大量文件夹的情况，可以考虑异步检查
