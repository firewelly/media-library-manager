# 媒体库管理系统功能模块文档

## 1. 文件移动管理功能

文件移动管理功能允许用户选择源文件夹和目标文件夹，扫描视频文件并执行移动或复制操作，同时可选择更新数据库中的文件路径信息。

### 1.1 核心功能实现

#### 1.1.1 扫描文件功能
- **功能描述**：扫描指定源文件夹中的所有视频文件，并在Treeview组件中显示文件列表
- **实现细节**：
  - 支持视频文件扩展名过滤（mp4、avi、mkv、mov、wmv、flv、webm、m4v）
  - 显示文件名、文件大小和文件状态
  - 使用后台线程执行扫描，避免界面卡顿
  - 实现进度条显示扫描进度
  - 支持取消扫描操作
  - 扫描完成后显示统计信息

#### 1.1.2 文件移动/复制功能
- **功能描述**：将选中的视频文件从源文件夹移动或复制到目标文件夹
- **实现细节**：
  - 支持移动和复制两种操作模式
  - 目标文件已存在时自动生成新文件名
  - 可选择是否更新数据库中的文件路径信息
  - 使用后台线程执行文件操作，避免界面卡顿
  - 实现进度条和统计信息显示
  - 支持批量提交数据库更改（每10个文件提交一次）
  - 提供操作结果统计（成功、失败、跳过的文件数量）
  - 文件移动/复制完成后可自动刷新视频列表

### 1.2 技术要点
- 使用`shutil`库实现文件的移动和复制操作
- 使用`threading`模块实现后台线程处理
- 使用`ProgressWindow`类显示操作进度
- 通过tkinter的`after`方法在主线程中更新UI
- 实现了完善的错误处理和异常捕获

## 2. 元数据管理功能

元数据管理功能包括重新导入不完整元数据、更新单个文件元数据等，确保媒体库中的视频信息完整准确。

### 2.1 重新导入不完整元数据

#### 2.1.1 功能描述
自动识别并重新导入元数据不完整的视频文件信息，包括时长、分辨率、文件创建时间和来源文件夹。

#### 2.1.2 实现细节
- **元数据不完整判定条件**：时长为空或为0、分辨率为空、文件创建时间为空、来源文件夹为空
- **统计阶段**：首先统计符合条件的视频数量，并显示确认对话框
- **处理阶段**：
  - 使用后台线程批量处理视频文件
  - 只更新确实需要更新的字段（原值为空且新值不为空时才更新）
  - 提供详细的日志记录和进度显示
  - 支持批量提交数据库更改（每20个视频提交一次）
  - 提供操作结果统计（成功、失败、跳过的文件数量）
- **完成后操作**：自动刷新视频列表

### 2.2 更新单个文件元数据

#### 2.2.1 功能描述
允许用户手动更新指定视频文件的元数据信息。

#### 2.2.2 实现细节
- **操作流程**：
  1. 查询视频文件的当前路径和文件名
  2. 检查文件是否存在
  3. 显示确认对话框
  4. 在后台线程中重新获取文件信息
- **更新的元数据**：文件大小、时长、分辨率、文件创建时间、来源文件夹、修改时间
- **完成后操作**：显示成功消息、刷新视频列表、如果当前选中的是该视频则刷新详情显示

## 3. 数据库重置功能

数据库重置功能允许用户在保留重要信息（标签和星级评分）的情况下，重新扫描并重建媒体库。

### 3.1 功能描述
完全重置数据库，同时基于MD5哈希值保留标签和星级评分信息，然后重新扫描所有活跃文件夹，导入视频文件信息。

### 3.2 实现细节

#### 3.2.1 操作流程
1. **确认阶段**：显示详细的确认对话框，说明操作的影响和选项（执行重置/仅备份/取消）
2. **备份阶段**：自动备份当前数据库到带时间戳的备份文件
3. **保存保留信息阶段**：保存所有带有MD5哈希值的视频文件的标签和星级评分信息
4. **清空数据阶段**：清空videos表中的所有数据
5. **重新扫描阶段**：扫描所有活跃文件夹中的视频文件，重新导入文件信息
6. **恢复保留信息阶段**：基于MD5哈希值匹配，恢复之前保存的标签和星级评分信息
7. **完成阶段**：显示重置结果统计，刷新界面显示

#### 3.2.2 技术要点
- 使用`shutil`库实现数据库备份
- 使用MD5哈希值作为文件唯一标识符，确保信息正确关联
- 实现了完善的进度显示和日志记录系统
- 支持中途取消操作
- 处理过程中自动跳过不存在的文件夹
- 对每个文件进行详细的错误处理和异常捕获

## 4. 批量生成封面功能

批量生成封面功能允许用户为视频文件批量生成或重新生成封面缩略图。

### 4.1 功能描述
为指定的视频文件批量生成封面缩略图，支持仅生成缺失的封面或重新生成所有封面。

### 4.2 实现细节

#### 4.2.1 操作流程
1. **调用方式**：支持从主菜单调用和从右键菜单调用两种方式
2. **确认阶段**：显示详细的确认对话框，说明操作的影响和选项（生成缺失封面/重新生成所有封面/取消）
3. **环境检查**：检查FFmpeg是否可用
4. **准备阶段**：创建进度窗口，包含进度条、统计信息和日志显示
5. **处理阶段**：在后台线程中批量处理视频文件，生成封面
6. **完成阶段**：显示处理结果统计

#### 4.2.2 视频筛选逻辑
- **从右键菜单调用**：只处理用户选中的视频文件
- **从主菜单调用**：处理当前筛选条件下的视频文件，包括：
  - 标题搜索条件
  - 标签搜索条件
  - 演员搜索条件
  - 星级筛选条件
  - 标签筛选条件
- 额外筛选条件：视频必须在线（NAS状态为在线），且文件格式为常见视频格式

#### 4.2.3 控制功能
- 支持暂停/继续操作
- 支持取消操作
- 提供实时的进度和统计信息显示
- 提供详细的日志记录

## 5. 功能特点总结

以上功能模块共同构成了媒体库管理系统的核心功能，具有以下特点：

1. **用户友好性**：提供直观的操作界面和详细的操作提示
2. **性能优化**：使用后台线程处理耗时操作，避免界面卡顿
3. **数据完整性**：实现了批量提交、事务处理和数据备份机制
4. **错误处理**：提供完善的错误处理和异常捕获机制
5. **用户控制**：支持暂停、继续和取消操作
6. **信息反馈**：提供实时的进度显示和详细的操作结果统计

这些功能模块相互配合，为用户提供了全面、高效的媒体库管理体验。
