# JAVDB信息更新器

## 工具概述

JAVDB信息更新器是一个合并了登录助手和批量信息获取功能的工具，旨在帮助用户一次性登录JAVDB账号后，批量更新媒体库中没有演员信息的视频。该工具使用专用的Edge浏览器配置文件来持久化登录状态，避免每次使用时都需要重新登录。

## 功能特点

- **登录状态持久化**：使用专用的Edge用户数据目录，登录一次后可多次使用
- **智能番号提取**：自动从文件名或标题中提取番号信息
- **批量更新**：支持选择特定文件夹或更新所有没有演员信息的视频
- **多信息获取**：获取包括标题、演员、标签、片商、发行日期、时长、评分和封面图片等详细信息
- **数据库更新**：自动将获取的信息更新到媒体库数据库
- **进度显示**：实时显示更新进度和统计信息
- **错误处理**：完善的错误处理和重试机制，确保稳定运行

## 系统要求

- Python 3.6或更高版本
- Microsoft Edge浏览器
- EdgeDriver（与浏览器版本匹配）
- 已安装必要的Python包：selenium, requests
- SOCKS5代理服务器（默认配置为127.0.0.1:1080）

## 安装说明

1. 确保已安装Microsoft Edge浏览器
2. 安装Python依赖：
   ```bash
   pip install selenium requests
   ```
3. 确保已安装与您的Edge浏览器版本匹配的EdgeDriver
   - 您可以使用项目中的`update_msedge_driver.py`脚本自动安装驱动
4. 确保SOCKS5代理服务器已正确配置并运行
5. 确保媒体库数据库文件`media_library.db`存在于同一目录

## 使用方法

1. 运行脚本：
   ```bash
   python javdb_information_updater.py
   ```

2. 首次运行时，工具会启动Edge浏览器并导航到JAVDB登录页面

3. 根据提示手动完成登录过程（如有安全验证，也需要手动完成）
   - 按回车键可以立即继续执行
   - 如不操作，最长等待5分钟

4. 登录成功后，工具会显示用户定义的文件夹列表
   - 输入文件夹编号选择特定文件夹进行更新
   - 输入0选择更新所有文件夹
   - 确认操作后开始批量更新

5. 工具会自动遍历选择的文件夹，提取番号，获取信息并更新数据库

## 核心流程说明

1. **登录助手功能**：
   - 创建专用的Edge用户数据目录（`.edge_driver_user_data`）
   - 启动浏览器并访问登录页面
   - 检测登录状态和安全验证
   - 等待用户手动完成登录
   - 验证登录是否成功
   - 持久化登录状态

2. **批量信息获取功能**：
   - 从数据库中获取没有演员信息的视频列表
   - 对于每个视频，尝试从数据库或文件名/标题中提取番号
   - 使用提取的番号在JAVDB上搜索并获取详情页URL
   - 解析详情页，提取演员、标签、片商等信息
   - 下载封面图片到`covers`目录
   - 将获取的信息更新到数据库
   - 显示进度和统计信息

## 配置信息

脚本中的主要配置参数如下：

- `SOCKS5_PROXY_HOST`: SOCKS5代理服务器地址（默认：127.0.0.1）
- `SOCKS5_PROXY_PORT`: SOCKS5代理服务器端口（默认：1080）
- `BASE_URL`: JAVDB基础URL（默认：https://javdb.com）
- `LOGIN_URL`: 登录页面URL
- `MIN_DELAY`, `MAX_DELAY`: 随机延迟范围（避免被反爬）
- `DB_PATH`: 数据库文件路径
- `COVERS_DIR`: 封面图片保存目录

如需修改这些配置，请直接编辑脚本文件中的相应参数。

## 注意事项

1. 请确保您的网络环境可以访问JAVDB网站
2. 请确保SOCKS5代理服务器已正确配置并运行
3. 登录后，专用的Edge用户数据目录会保存您的登录状态，下次运行时无需重新登录
4. 如果长时间未使用或登录状态失效，系统会自动提示重新登录
5. 批量更新过程中，请不要关闭浏览器窗口
6. 如有大量视频需要更新，建议分批进行，以避免被JAVDB的反爬机制限制
7. 封面图片会保存在`covers`目录下，如果该目录不存在，系统会自动创建

## 常见问题

**Q: 浏览器启动失败怎么办？**
A: 请检查Edge浏览器是否正确安装，以及EdgeDriver是否与浏览器版本匹配。您可以运行`update_msedge_driver.py`脚本来自动安装匹配的驱动。

**Q: 登录后仍然无法获取信息怎么办？**
A: 请检查您的SOCKS5代理配置是否正确，以及是否可以正常访问JAVDB网站。另外，某些情况下可能需要手动刷新页面或重新登录。

**Q: 无法提取番号怎么办？**
A: 请检查文件名格式是否标准，如果文件命名不规范，可能导致无法正确提取番号。您可以手动在数据库中添加正确的番号信息。

**Q: 更新数据库失败怎么办？**
A: 请确保您对数据库文件有写权限，并且数据库文件没有被其他程序锁定。
