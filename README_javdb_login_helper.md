# JAVDB 登录助手使用指南

## 功能简介

**javdb_login_helper.py** 是一个专用的登录助手脚本，基于 MS Edge 浏览器，帮助您在需要访问 JAVDB 的爬虫脚本中持久化登录状态，避免每次运行都需要重新登录的麻烦。

## 主要特性

- 使用专用的 Edge 用户数据目录存储登录状态（位于 `.edge_driver_user_data/`）
- 支持 SOCKS5 代理设置（默认使用 127.0.0.1:1080）
- 登录时提供 5 分钟等待时间，用户完成登录后可直接按回车跳过等待
- 自动检测并处理安全验证页面
- 跨平台支持（Windows、macOS、Linux）
- 模拟人类操作模式，降低被检测为自动化工具的风险

## 如何使用

### 首次使用

1. 在终端中运行脚本：
   ```bash
   python3 javdb_login_helper.py
   ```
   或直接执行（已设置可执行权限）：
   ```bash
   ./javdb_login_helper.py
   ```

2. 脚本会自动启动 MS Edge 浏览器并打开 JAVDB 登录页面

3. 请手动完成登录操作（包括可能的安全验证）

4. 登录成功后，可以关闭浏览器，登录状态会被保存到专用的用户数据目录中

### 后续使用

- 之后运行任何需要访问 JAVDB 的爬虫脚本时，只要这些脚本也使用了相同的用户数据目录策略，就会自动重用已保存的登录状态，无需再次登录

### 注意事项

- 请确保您已安装 MS Edge 浏览器
- 如需更改代理设置，请直接编辑脚本中的 `SOCKS5_PROXY_HOST` 和 `SOCKS5_PROXY_PORT` 变量
- 如果遇到浏览器驱动相关问题，请确保安装了与您的 Edge 浏览器版本匹配的 EdgeDriver
- 用户数据目录 `.edge_driver_user_data/` 包含您的登录信息，请妥善保管，不要分享给他人
