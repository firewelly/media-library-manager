设计说明

  • 设计令牌：tokens.css 定义字体、间距、圆角、布局尺寸等全局变量，与主题无关
  • 双主题：theme-dark.css（琥珀金 + 玻璃拟态）与 theme-light.css（青蓝 + 云母质感）通过 CSS 变量切换
  • 公共组件：common.css 包含按钮、搜索框、筛选 chip、虚拟列表、星级、骨架屏、详情面板、状态栏等
  • 虚拟滚动：列表页使用骨架屏行演示向下滚动时的懒加载占位效果
  • 画板导航：每个页面底部有统一的画板导航条，方便在各设计稿间切换
  • 列配置：主界面列表支持 18 列配置，设计稿中展示了最常用的 9 列
  • 封面比例：统一使用 2:3 竖版海报比例（--cover-ratio: 0.6667）
