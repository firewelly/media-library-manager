# NFO文件导入功能使用指南

## 📋 功能概述

NFO文件导入功能允许用户将本地的NFO文件信息导入到媒体库中，自动更新视频的元数据信息，包括标题、番号、演员、标签等信息。

## 🎯 核心功能特性

### 1. javdb_title映射（新功能）
- **直接映射**：javdb_title字段直接映射NFO文件中`<title>`标签的完整内容
- **保持完整**：不再自动分割标题，完整保留原始标题信息
- **一致性**：确保javdb_title与title字段内容一致

### 2. 番号提取优化
- **智能提取**：从标题中智能提取番号信息
- **格式识别**：支持多种番号格式（ABC-123、ABC123等）
- **正则增强**：使用正则表达式作为备选提取方式

### 3. 批量导入支持
- **文件夹级别**：支持按文件夹批量导入NFO信息
- **缺失检测**：可针对缺少特定信息的视频进行批量导入
- **进度显示**：提供详细的导入进度和日志信息

## 🔧 使用方法

### 基本导入流程

1. **准备NFO文件**
   ```
   视频文件：video.mp4
   NFO文件：video.nfo
   ```

2. **NFO文件格式要求**
   ```xml
   <?xml version="1.0" encoding="utf-8" standalone="yes"?>
   <movie>
       <title>IPX-123 美咲かんな 新人デビュー</title>
       <plot>剧情描述</plot>
       <year>2024</year>
       <premiered>2024-01-01</premiered>
       <genre>类型</genre>
       <rating>8.5</rating>
       <studio>工作室</studio>
       <uniqueid type="num" default="true">IPX-123</uniqueid>
       <tag>标签1</tag>
       <tag>标签2</tag>
       <actor>
           <name>美咲かんな</name>
       </actor>
   </movie>
   ```

### 批量导入功能

#### 针对无演员信息的视频
1. 在界面中选择目标文件夹
2. 点击"批量导入NFO信息（无演员）"按钮
3. 系统会自动查找该文件夹下缺少演员信息的视频
4. 查找对应的NFO文件并导入信息
5. 显示导入进度和结果统计

#### 导入内容包含
- **基本信息**：标题、番号、年份、发行日期
- **描述信息**：剧情描述、类型、评分、工作室
- **人员信息**：演员列表
- **标签信息**：标签列表
- **唯一标识**：番号ID

## 📊 映射规则说明

### 字段映射表
| NFO标签 | 数据库字段 | 说明 |
|---------|------------|------|
| `<title>` | `title` | 完整标题 |
| `<title>` | `javdb_title` | 完整标题（直接映射） |
| 提取番号 | `code` | 自动提取的番号 |
| `<plot>` | `description` | 剧情描述 |
| `<year>` | `year` | 年份 |
| `<premiered>` | `release_date` | 发行日期 |
| `<genre>` | `genre` | 类型 |
| `<rating>` | `rating` | 评分 |
| `<studio>` | `studio` | 工作室 |
| `<uniqueid>` | `serial_number` | 番号ID |
| `<tag>` | `tags` | 标签列表 |
| `<actor><name>` | `actors` | 演员列表 |

### 番号提取规则

#### 基本提取
1. **空格分割**：优先使用第一个空格前的内容作为番号
2. **格式验证**：检查是否符合常见番号格式

#### 增强提取（当基本提取失败时）
1. **正则匹配**：使用正则表达式查找番号格式
2. **模式识别**：支持ABC-123、ABC123等格式
3. **特殊处理**：支持FC2、1PONDO等特殊前缀

#### 番号格式示例
- **标准格式**：IPX-123、ABC-456
- **无分隔符**：IPX123、ABC456
- **特殊格式**：FC2-PPV-1234567、1PONDO-012345

## ⚙️ 配置选项

### 当前配置
目前javdb_title采用**直接映射**模式，无需额外配置。

### 未来扩展（计划中）
```json
{
    "nfo_import": {
        "title_mapping_mode": "direct",  // direct: 直接映射, split: 分割映射
        "auto_extract_code": true,       // 是否自动提取番号
        "code_extraction_patterns": [     // 番号提取正则表达式
            "\\b([A-Za-z]{2,})-?(\\d{3,})\\b",
            "FC2-(\\d{7,})"
        ],
        "update_existing_data": true,     // 是否更新已有数据
        "import_empty_fields": false      // 是否导入空字段
    }
}
```

## 🛠️ 故障排除

### 常见问题

#### 1. NFO文件无法识别
**症状**：导入时提示找不到NFO文件
**解决**：
- 确保NFO文件与视频文件同名
- 检查文件扩展名是否为.nfo
- 确认文件编码为UTF-8

#### 2. 信息导入不完整
**症状**：部分信息未成功导入
**解决**：
- 检查NFO文件格式是否符合XML规范
- 确认所有必填标签都存在
- 查看导入日志了解具体错误

#### 3. 番号提取错误
**症状**：提取的番号不正确
**解决**：
- 检查标题格式是否标准
- 手动指定番号在`<uniqueid>`标签中
- 使用标准番号格式（如IPX-123）

#### 4. 演员信息未导入
**症状**：演员信息缺失
**解决**：
- 确认NFO文件包含`<actor>`标签
- 检查`<name>`子标签是否存在
- 验证演员名称格式
