# 媒体库管理系统项目概述
 - 版本: v2.1.0
 - 最后更新: 2026-08-12
 - 适用系统: Windows/macOS/Linux

## 1. 项目简介

媒体库管理系统是一个功能完备的视频内容管理平台，专注于视频文件的组织、分析、去重和元数据管理。该系统结合了网络爬虫、视频内容分析、数据库管理和用户界面等多个组件，提供了从视频元数据获取、内容特征分析到重复文件检测与清理的全流程解决方案。

## 2. 系统架构

系统采用模块化设计，主要包含以下核心组件：

1. **数据爬取模块**：通过网络爬虫从JAVDB等网站获取视频元数据，包括标题、演员、标签、发行日期等信息。

2. **视频分析模块**：提供多模态视频内容分析功能，支持基于SiliconFlow API的GLM-4.1V-9B-Thinking模型视频分析器，能够提取视频帧（最大30帧）并使用AI模型进行内容理解和智能标签匹配。

3. **数据库管理模块**：基于SQLite构建的数据库系统，存储视频元数据、演员信息、标签和文件关联等数据。

4. **文件管理模块**：负责视频文件的导入、路径管理、MD5计算和完整性检查。

5. **去重与清理模块**：检测并清理重复视频记录，支持多种去重策略。

6. **批量处理模块**：提供批量视频分析、元数据更新等功能，支持并行处理以提高效率。

## 3. 核心功能

### 3.1 视频元数据获取
- 支持通过番号搜索特定视频信息
- 自动获取视频封面、演员信息、标签等元数据
- 支持批量爬取和单视频爬取两种模式
- 实现了代理支持和反爬虫策略
- 视频信息更新工具：支持番号提取与格式化、数据库操作、视频信息更新、JAVDB信息爬取等功能
- 演员档案修复工具：支持演员头像URL提取、头像下载、重复演员合并、从视频封面提取人脸作为头像等功能

### 3.2 视频内容分析
- 基于多模态AI模型的视频内容理解
- 自动抽取视频帧并进行图像分析
- 支持自定义标签词汇库匹配
- 生成详细的分析报告和标签频率统计

### 3.3 数据库管理
- 完整的数据库表结构设计（8个主要表）
- 支持SQLite数据库操作
- 提供数据库备份和恢复功能
- 实现了数据完整性约束和索引优化

### 3.4 重复视频检测与清理
- 支持基于文件路径、文件名和MD5值的重复检测
- 提供交互式清理界面，允许用户选择删除重复记录
- 自动处理关联数据的级联删除
- 提供详细的重复检测报告

### 3.5 批量处理功能
- 支持批量导入和更新视频元数据
- 实现并行视频分析以提高效率
- 支持SMB网络路径访问
- 提供断点续传和错误恢复机制

## 4. 技术栈

- **编程语言**：Python 3.x
- **数据库**：SQLite
- **网络爬虫**：Requests, Selenium
- **视频处理**：OpenCV (cv2), PIL
- **AI模型集成**：SiliconFlow API (GLM-4.1V-9B-Thinking), LM Studio API (qwen2.5-vl-7b)
- **数据处理**：Pandas, NumPy, JSON, CSV
- **GUI框架**：PySide6（pyside_v4 主界面）、Tkinter（旧版界面）
- **Web技术**：HTML, CSS, JavaScript (用于设计稿和旧版GUI)
- **AI模型**：Qwen3-VL-30B-A3B-Instruct（视频内容分析）
- **操作系统支持**：跨平台 (Windows, macOS, Linux)

## 5. 项目结构

项目采用模块化的文件组织结构，将不同功能的脚本分离到独立文件中，便于维护和扩展。主要目录和文件说明：

- **核心脚本文件**：包含各种功能实现的Python脚本
- **数据库相关**：数据库模式文档、ER图和初始化脚本
- **配置文件**：系统配置、GUI配置等
- **文档目录**：包含各类技术文档和使用指南
- **测试目录**：测试脚本和示例
- **媒体资源**：封面图片存储目录
- **报告目录**：生成的分析报告和检查报告

## 6. 前端界面（pyside_v4）

### 6.1 设计系统
- **设计风格**：深色影院风（琥珀金 + 玻璃拟态），设计稿位于 `ui_design/`
- **双主题支持**：深色/浅色主题可切换
- **组件体系**：tokens.css + theme-dark.css + theme-light.css + common.css

### 6.2 技术架构
- **框架**：PySide6（Qt for Python）
- **目录结构**：`pyside_v4/` 包含 core/、theme/、widgets/、windows/、dialogs/、workers/
- **异步加载**：QThread 后台数据加载，不阻塞 UI
- **性能优化**：数据库查询 14 秒 → 9 毫秒，64MB cache_size

### 6.3 功能覆盖
- 57 个功能模块，100% 完成率
- 完整菜单系统（文件/工具/界面/帮助）
- 右键菜单（单文件/多文件批量操作）
- 详情面板（13 项信息展示与编辑）
- 对话框（演员库、标签管理、扫描进度、设置、文件夹管理、智能更新、去重等）

## 7. 存储环境

### 7.1 本地存储
- 视频分布在本地 `/Users/firewell` 目录

### 7.2 NAS 存储
- 视频分布在 NAS 卷 `/Volumes/app`、`/Volumes/Video`、`/Volumes/国产_DX4600`、`/Volumes/HC530_1`、`/Volumes/Jav_HDD4`
- NAS 未挂载时大量视频 `file_path` 不可达，打标签脚本会用 `os.path.exists` 二次过滤

- Python 3.7或更高版本

## 10. 使用流程

1. **初始化**：运行初始化脚本创建数据库
2. **配置**：设置config.json和config.py中的参数
3. **导入**：使用导入脚本添加视频文件
4. **爬取元数据**：运行爬虫脚本获取视频元数据
5. **内容分析**：使用视频分析工具分析视频内容
6. **去重清理**：检测并清理重复视频记录
7. **维护更新**：定期运行更新脚本保持数据最新
