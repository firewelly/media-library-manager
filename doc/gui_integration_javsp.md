# PySide6 GUI 集成 JavSP 指南
 - 版本: 开发版
 - 最后更新: 2025-11-29
 - 适用系统: Windows/macOS/Linux

## 按钮与面板
- 详情页按钮“获取JAV信息”调用 `utils.jav` 完成搜索与保存。
- 菜单“批量导入JAV信息”针对无标题视频执行批量导入。
- 工具菜单“JAV信息面板”打开 `JavInfoDialog`，支持手动输入番号与保存到当前选中视频。

## 进度与错误处理
- 状态栏显示进度与结果统计；异常以弹窗显示。
- 搜索失败不写库；保存失败提示错误。

## 设置与代理
- 如需代理与策略优先级，可在后续引入 `settings.json` 持久化；当前使用默认 JavSP 搜索接口。
