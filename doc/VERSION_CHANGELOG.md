# Media Library Manager - 版本更新日志

## 版本 v2.1.0 (2026-08-12) - pyside_v4 前端重构与系统稳定性增强

### 核心更新

#### 1. pyside_v4 前端界面重构
- **全新设计系统**：基于深色影院风设计稿（琥珀金 + 玻璃拟态），创建完整 UI 组件体系
- **完整功能实现**：57 个功能模块，100% 完成率，覆盖原 pyside 版本全部功能
- **架构优化**：core/widgets/windows/dialogs/workers 分层架构，异步数据加载
- **性能提升**：数据库查询从 14 秒降至 9 毫秒，64MB 缓存优化
- **详细迁移计划**：`pyside_v4/MIGRATION_PLAN.md`，分 6 阶段实施完成

#### 2. MD5 完整性修复
- **Bug 修复**：`fast_smart_media_updater.py` 文件名匹配被 `enable_md5` 错误 gate，导致移动检测失效
- **NAS 计算脚本改进**：`md5_calc_nas.sh` 去掉 set -e、修复路径映射、增加超时保护
- **批量计算完成**：14,770 条任务成功计算 13,940 条，MD5 覆盖率从 69.8% 提升至 97.9%

#### 3. 视频批量打标签系统
- **AI 模型集成**：`Qwen/Qwen3-VL-30B-A3B-Instruct` 视觉模型自动打标签
- **批量处理**：本机 627 个视频完成标签更新，354 条成功更新
- **诊断增强**：批量标注功能增加可达/不可达统计和具体原因提示

#### 4. NAS 存储迁移
- **DXP4800 迁移**：本机 AV 库 64 个视频 + Essay2T 59 个番号文件夹迁移完成
- **路径映射验证**：4 个 NAS 卷的 macOS/NAS 路径映射已验证并文档化
- **数据库同步**：迁移后数据库记录全部更新，无残留旧路径

#### 5. 数据库与文件管理
- **去重清理**：国产mac 132 组重复文件清理，删除 132 条数据库记录
- **路径修正**：4,739 条记录路径修正，本地 679 条无标签视频全部可达
- **多文件分析**：完成 JAV 分碟/多版本分析，287 个番号 670 文件分类整理

#### 6. 安全与隐私
- **凭证清理**：git remote URL、macOS keychain、git 历史中的凭证全部清除
- **.gitignore 增强**：新增敏感凭证忽略规则（.env、*.pem、*.key 等）
- **安全规范**：token 只放 shell 环境变量或外部密码管理器，不进项目文件

## 版本 v2.0.0 (2025-12-27) - 里程碑版本
**提交信息**: 完成 PySide6 版本功能补全，重构核心逻辑为 Utils 模块

### 🚀 核心更新

#### 1. PySide6 版本功能完整化
- **功能对齐**: PySide6 版本现已具备旧版 Tkinter 版本的全部核心功能。
- **批量操作增强**: 
  - 批量计算 MD5
  - 批量导入 NFO / JavDB 信息
  - 批量移动文件
  - 批量清理文件名
  - 批量自动打标签
  - 批量迁移/复制 JavSP 数据
- **右键菜单重构**: 提供更丰富的上下文操作选项，支持多选操作。
- **新对话框**: 新增可视化文件移动管理器 (`FileMoveDialog`)。

#### 2. 代码架构重构
- **Utils 模块分离**: 将核心业务逻辑从 GUI 代码中剥离，封装到 `utils/` 目录。
  - `utils/batch_ops.py`: 统一管理所有批量操作逻辑。
  - `utils/maintenance.py`: 包含智能去重、星级同步、数据清理等维护功能。
  - `utils/thumbnails.py`: 独立的缩略图生成器，支持 GPU 加速检测。
- **依赖解耦**: 通过 wrapper 模块 (`code_extractor`, `javsp_integration`) 解决循环依赖问题。

#### 3. 用户体验优化
- **异步处理**: 所有耗时的批量操作均在后台线程运行，界面不再卡顿。
- **进度反馈**: 提供详细的进度条和日志显示。
