Tk 经典版 — media_library.py

最初的单文件应用程序（约 12,600 行）。提供完整的 Tkinter GUI，并作为 PySide6 v2 的后端逻辑库。

类：MediaLibrary

该单体类包含： - 数据库：SQLite 连接、游标，以及对 videos、actors、video_actors、javdb_info、javdb_tags、folders 的所有 CRUD 操作。 - 文件操作：扫描目录，计算 MD5/SHA 哈希值，检测移动，导入视频，管理封面。 - 元数据：JAVDB 抓取（通过 javdb_crawler_single.py 子进程），NFO 导入，标签管理，演员管理。 - GUI：具有可配置列、右键上下文菜单、键盘快捷键、拖拽重排列功能的 Tkinter Treeview。 - 批量操作：按 MD5 去重，批量重命名，批量打标签，批量删除。

列配置

列布局持久化保存在 gui_config.json 中。每列包含 width、position 和 text 字段。Treeview 支持： - 拖拽调整列宽（通过 on_column_resize_end + save_column_config_after_resize） - 拖拽重排列（通过 on_drag_end + swap_columns + recreate_treeview）

有关历史列宽持久化 bug 的根因分析，请参阅 fix_column_resize_plan。

启动

python media_library.py
# or via shell wrapper:
./start_media_library.sh    # macOS / Linux

作为后端库的角色

当 PySide6 v2 启动时，gui_adapter.setup_full_integration(qt_window) 会将 MediaLibrary 中约 166 个方法动态绑定到 Qt 窗口对象上。这意味着： - Tk 的文件扫描、MD5、导入、JAVDB 抓取、标签管理等均被原封不动地复用。 - Tk GUI 本身在 v2 模式下不会显示 —— 仅使用其方法。 - 对 MediaLibrary 后端方法的任何 bug 修复都会同时惠及这两个 GUI。

关键方法（后端，被 v2 复用）

方法 用途
scan_and_import_folder() 扫描目录，计算 MD5，插入新视频
deduplicate_by_md5() 通过 MD5 哈希查找并合并重复条目
fetch_javdb_info() 抓取单个视频番号的元数据
batch_update_tags() 将标签更改应用于选定的视频
manage_actors() 演员 CRUD、头像下载、合并演员
export_csv() / import_nfo() 数据导入/导出
