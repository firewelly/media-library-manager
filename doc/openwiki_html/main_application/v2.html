PySide6 v2（pyside_v2 包）

PySide6 v2 — pyside_v2 包

推荐的 GUI。一个模块化的 PySide6 包，具有双主题、高性能分页表格、异步查询和演员网格浏览器。

运行时初始化

pyside_v2/app.py 在任何导入之前执行一个关键步骤：它将 sys.argv[0] 锚定到项目根目录，以便 utils/runtime.runtime_dir() 解析为项目根目录（media_library.db 所在位置），而不是 pyside_v2/。这是必需的，因为运行时解析器使用 sys.argv[0] 作为其基础路径。

性能架构

场景 Tk 经典版 PySide6 v2 提升
首页加载（49k 个视频） ~31s（全表 JOIN） 0.5s（分页） 60 倍
热搜索 阻塞 UI 0.1–0.6s 异步 非阻塞
翻页 全量重新查询 0.04s 已缓存

关键优化： - 复合索引：在 videos 上建立 (is_nas_online, file_created_time) - 子查询模式：使用 id IN (SELECT ...) 替代 OR LIKE 链 - QAbstractTableModel：每页仅加载 300 行；data() 按需提供单元格数据 - QueryWorker：所有搜索在 QThread 中运行，确保 UI 线程保持响应

双主题系统

两种主题支持一行代码切换，并持久化在 gui_config.json 中： - 深色（影院）：深色背景搭配琥珀金点缀 - 浅色（流畅）：干净的白色搭配青蓝点缀

theme/colors.py 定义设计令牌。theme/theme_manager.py 处理加载、切换和持久化。theme/base.qss 是一个共享模板，包含 {{placeholder}} 令牌，由 colors.py 按主题填充。

演员浏览器（v2 专属）

dialogs/actor_browser.py — 所有演员的网格卡片视图，包含头像、姓名和作品数量。支持搜索、排序、收藏筛选和分页。点击演员会打开 actor_detail.py。这取代了 Tk 版本中的单演员搜索方式。

SQL 封装

在 v2 重构之后，所有 SQL 执行都集中在 MediaLibraryCore（core/bridge.py）中。组件和对话框不包含 cursor.execute 调用——它们调用返回数据的核心方法。这由 tests/test_v2_refactor.py 验证。
