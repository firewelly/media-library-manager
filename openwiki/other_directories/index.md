# 文件

- [人脸识别模块](facereco.md) - 介绍 facereco/ 目录 — 人脸提取 API（包含 Haar 级联检测、质量评分、多人提取的 FaceExtractorAPI）及示例用法脚本。
- [其他目录概览](overview.md) - 支持性目录概览 — facereco（人脸提取 API）、video_analyzer（AI 视频内容分析）和 utils（提供数据库、文件操作、批量操作等功能的共享工具模块）。
- [Utils 模块](utils.md) - 记录 utils/ 共享工具模块 — DatabaseManager、FileUtils、BatchOperationManager、MaintenanceManager、ThumbnailGenerator、media_extensions（NFO 导入、去重、自动打标签）、进度跟踪以及运行时路径解析。
- [视频分析器模块](video_analyzer.md) - 介绍 video_analyzer/ 目录——使用 SiliconFlow API（Qwen3-VL-30B-A3B MoE 模型）进行 AI 视频内容分析、帧提取流水线、GUI 适配器桥接以及词汇标签系统。
